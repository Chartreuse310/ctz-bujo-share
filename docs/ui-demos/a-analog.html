2026 年 10 月月历列表

每天一条日总结，按日期倒序。这个视图里只有日总结，要看条目请进日页。

  • 30周五

    十月要结束了

    翻了一遍这个月的记录，重点集中在论文和绘画上，跑量比上个月少了一些。晚上把速写本摊开重排了一遍顺序，舒服多了。

    →
  • 27周二

    构图还是不对，先放着

    想把两个主体压在同一侧，结果重心全塌了。决定先不画，去看两天画册再说。

    →
  • 25周日

    录了一小段，杂音很多

    用手机直接录的，底噪明显。当作留个时间戳吧，明年再听应该会觉得很有意思。

    →
  • 22周四

    和导师聊完，方向收窄了

    原以为要补一整章，其实只要把第三节的论证换一个顺序。收窄之后反而松了。

    →
  • 20周二

    合上书的时候有点舍不得

    读了二十天，最后三十页特意放慢。读完在封底空白处写了日期。

    →
  • 18周日

    跑步时想通的事

    跑到第七公里突然想明白，纠结的不是选哪个方向，是怕选错。继续跑。

    →
  • 16周五

    换了纸，笔尖的阻力变了

    新纸克数高，铅笔的涩感回来了。同一支笔画出完全不同的线。

    →
  • 14周三

    把想法画成图，一下清楚了

    用三根横轴把「已定 / 待验 / 存疑」摆开，之前绕了半个月的问题一眼就看出卡在哪。

  • 11周日

    重读第三章，发现一个漏洞

    去年写的过渡段其实没接上。补了半页，比新写一段还费劲。

    →
  • 08周四

    画到第 12 张，手感回来了

    前十一张都是热身。第十二张的线终于不抖了。

  • 06周二
